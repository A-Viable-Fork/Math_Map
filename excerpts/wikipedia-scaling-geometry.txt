Therefore, given a function <math>y=f(x)</math>, the equation of the dilated function is
: <math>y=nf\left(\frac{x}{m}\right).</math>

* If <math>n=1</math>, the transformation is horizontal; when <math>m > 1</math>, it is a dilation, when <math>m < 1</math>, it is a contraction.

* If <math>m=1</math>, the transformation is vertical; when <math>n>1</math> it is a dilation, when <math>n<1</math>, it is a contraction.

for <math>m,n \in \R^+</math>.
