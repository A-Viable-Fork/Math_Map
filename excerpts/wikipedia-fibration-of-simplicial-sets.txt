The maps having the right lifting property with respect to inner anodyne extensions or equivalently with respect to the horn inclusions <math>\Lambda^n_k \to \Delta^n, \, n \ge 1, 0 < k < n</math> are called '''inner fibrations'''.

Thus, a map is a left (resp. right) fibration if and only if it has the [[right lifting property]] with respect to left (resp. right) anodyne extensions.

a map is a left (resp. right) fibration if and only if it has the [[right lifting property]] with respect to left (resp. right) anodyne extensions.
