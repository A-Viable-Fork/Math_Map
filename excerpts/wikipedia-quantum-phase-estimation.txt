the '''quantum phase estimation algorithm''' is a [[quantum algorithm]] to estimate the phase corresponding to an eigenvalue of a given [[Unitary matrix|unitary operator]].

the algorithm returns [[with high probability]] an approximation for <math>\theta</math>, within additive error <math>\varepsilon</math>, using <math>n=O(\log(1/\varepsilon))</math> qubits in the first register

Thus if <math>| \psi \rangle</math> is an [[ Eigenvalues and eigenvectors |eigenvector]] of <math>U</math>

uses of controlled-U, and this is optimal.
