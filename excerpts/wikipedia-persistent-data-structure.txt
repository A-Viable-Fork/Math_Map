A data structure is '''partially persistent''' if all versions can be accessed but only the newest version can be modified.

Driscoll, Sarnak, [[Daniel Sleator|Sleator]], [[Robert Tarjan|Tarjan]] came up<ref name=Driscoll /> with a way to combine the techniques of fat nodes and path copying, achieving O(1) access slowdown and O(1) amortized overhead in space and time per

Their method strictly assumes a [[linked data structure]] where the ''in-degree'' (the maximum number of incoming pointers pointing to any single node) is bounded by a known constant
