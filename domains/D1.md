## D1-001 Transpose graph

*Transformer; involution, representation-change, orientation; origin: map; tier: landed*

Reverses all edge orientations in a directed graph. Each directed edge (u,v) becomes (v,u).

- input: Directed graph G = (V, E)
- output: Directed graph G^T = (V, E') where E' = {(v,u) : (u,v) in E}
- preserved: Vertex set, strongly connected components (as sets), degree sequence (in/out swapped)
- broken: Edge orientation, directed path structure, reachability ordering
- complexity: O(|V| + |E|)
- evidence: name unchecked, description unchecked, input unchecked, output unchecked, preserved unchecked, broken unchecked

## D1-002 Complement graph

*Transformer; involution, representation-change; origin: map; tier: landed*

Produces the graph on the same vertex set where two vertices are adjacent if and only if they are not adjacent in the original.

- input: Simple graph G = (V, E)

- complexity: O(|V|^2) to construct adjacency; O(1) conceptually

## D1-003 Line graph

*Transformer; representation-change; origin: map; tier: audited (imprecise)*

Constructs a new graph L(G) whose vertices are the edges of G, with two vertices in L(G) adjacent when their corresponding edges in G share an incident vertex. Translates Eulerian cycles to Hamiltonian cycles. Iterated application yields deterministic terminal behaviors (stabilizes as cycle, collapses, terminates as triangle, or expands). Whitney Isomorphism Theorem: G is recoverable from L(G) for connected graphs except K_3 vs K_{1,3}.

- input: Undirected graph G = (V, E)
- output: Undirected graph L(G) = (E, E') where E' encodes edge-adjacency
- preserved: Edge count becomes vertex count; Eulerian property translates to Hamiltonian property
- broken: Vertex-edge distinction (edges become vertices), vertex count, degree distribution
- complexity: O(|E| * max_degree)
- evidence: name sourced, description sourced, input sourced, output formal, preserved imprecise, broken sourced
- Mathlib (exact, on output): [`SimpleGraph.lineGraph`](https://github.com/leanprover-community/mathlib4/blob/380f2aafb622cb2c1c93dac545b6389083c68c51/Mathlib/Combinatorics/SimpleGraph/LineGraph.lean). The line graph is a simple graph on G.edgeSet: its vertices are the edges of G, so edge count becomes vertex count by definition.
- Mathlib (exact, on description): [`SimpleGraph.lineGraph_adj_iff_exists`](https://github.com/leanprover-community/mathlib4/blob/380f2aafb622cb2c1c93dac545b6389083c68c51/Mathlib/Combinatorics/SimpleGraph/LineGraph.lean). Two edges are adjacent in L(G) iff they are distinct and share a vertex. The entry's further claims (Eulerian to Hamiltonian, Whitney's theorem) are not in Mathlib at the pin.

## D1-004 Graph minor

*Transformer; compression, surgery; origin: map; tier: landed*

A graph H obtained from G by any sequence of edge deletions, vertex deletions, and edge contractions. The Graph Minor Theorem (Robertson-Seymour) establishes that the minor ordering is a well-quasi-ordering, enabling forbidden minor characterizations of graph families.

- input: Graph G + specification of deletion/contraction operations
- output: Minor graph H
- preserved: Topological properties characterized by forbidden minors (planarity, bounded treewidth, linkless embeddability)
- broken: Vertex/edge count, specific structure, metric properties
- complexity: Polynomial per operation; minor testing is NP-complete in general
- evidence: name unchecked, description unchecked, input unchecked, output unchecked, preserved unchecked, broken unchecked

## D1-006 Power of graph (G^k)

*Transformer; densification, parameterized; origin: map; tier: landed*

Connects vertices whose path distance in G is at most k. For a graph of diameter d, G^d is complete. Monotone in connectivity. G^2 models wireless interference (vertices sharing common neighbors). Determining whether a graph is the square of another is NP-complete.

- input: Graph G = (V, E) + positive integer k
- output: Dense graph G^k = (V, E') where (u,v) in E' iff dist_G(u,v) <= k
- preserved: Vertex set, connectivity (monotonically increased)
- broken: Sparsity, path structure, distance metric (collapsed), chromatic number (may increase)
- complexity: O(|V|^3) via matrix multiplication (BFS per vertex: O(|V|(|V|+|E|)))
- evidence: name unchecked, description unchecked, input unchecked, output unchecked, preserved unchecked, broken unchecked

## D1-012 YΔ-transformation (Wye-Delta)

## D1-014 Mycielskian

*Transformer; construction, expansion, generative; origin: map; tier: landed*

## D1-040 Chordal completion (triangulation)

*Transformer; completion, algebra-bridge; origin: map; tier: landed*

Adds edges to eliminate all induced cycles of length >= 4, making the graph chordal. Directly equivalent to Gaussian elimination fill-in of sparse symmetric matrices: minimal chordal completion corresponds to a fill-in pattern, and the elimination ordering derives from the resulting chordal graph. Minimum chordal completion and minimum fill-in are both NP-complete.

- input: Graph G = (V, E)
- output: Chordal graph G' = (V, E ∪ F) where F is the fill edge set
- preserved: Vertex set, original edges (augmentation only), connectivity
- broken: Sparsity (edges added), induced cycle structure (all long cycles get chords)
- complexity: NP-complete (minimum fill-in); polynomial for minimal completion
- evidence: name unchecked, description unchecked, input unchecked, output unchecked, preserved unchecked, broken unchecked
