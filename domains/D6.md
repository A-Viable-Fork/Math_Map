## D6-001 Abel transform

*Transformer; projection, representation-change; origin: map*

Projects axisymmetric 2D density to 1D line profile via line-of-sight integration. Inverse is Abel inversion.

- input: Axisymmetric function f(r)
- output: Line integral projection g(y)
- preserved: Axisymmetry encoding, invertibility (Abel inversion)
- broken: 2D spatial structure (projected to 1D)
- complexity: O(n) per profile point

## D6-002 Aboodh transform

*Transformer; representation-change; origin: map*

Scaled Laplace variant: A{f}(v) = (1/v)int_0^inf f(t)e^{-vt}dt. Simplifies boundary conditions for fractional ODEs.

- input: Function f on [0,inf)
- output: Aboodh transform A{f}(v)
- preserved: Laplace-type properties, fractional ODE simplification
- broken: Standard Laplace form
- complexity: O(integration cost)

## D6-004 Aluthge transform

*Transformer; surgery, iterative; origin: map*

tilde-T = |T|^{1/2} U |T|^{1/2} for T = U|T|. Moves operator toward normality. Preserves spectrum.

- input: Operator T with polar decomposition T=U|T|
- output: Aluthge transform tilde-T
- preserved: Spectrum, p-hyponormality improvement
- broken: Non-normal structure (reduced)
- complexity: O(N^3) for N-dim matrices

## D6-008 Baker's transformation

*Transformer; surgery; origin: map*

Cuts unit square in half, stretches, restacks. Canonical model of deterministic chaos. Bernoulli system.

## D6-013 Bilinear transform

*Transformer; representation-change; origin: map*

## D6-018 Cayley transform

*Transformer; representation-change; origin: map*

## D6-021 Choi's theorem on CP maps

*Transformer; construction; origin: map*

## D6-022 Continuous Fourier transform

*Transformer; representation-change; origin: map*

int f(t)e^{-2pi iut}dt. Kernel: complex exponential. Maps L^1/L^2 to spectral domain. Plancherel isometry on L^2.

- input: Function f in L^1(R) or L^2(R)
- output: Fourier transform f-hat in frequency domain
- preserved: L^2 norm (Parseval/Plancherel), convolution -> multiplication
- broken: Pointwise values, time localization (uncertainty principle)
- complexity: O(n log n) via FFT for discrete; formal integral for continuous

## D6-032 Discrete Fourier transform

*Transformer; representation-change; origin: map*

DFT: X_k = sum_{n=0}^{N-1} x_n e^{-2pi ikn/N}. N-point. Assumes periodicity.

- preserved: Parseval, periodicity assumption, convolution -> multiplication
- broken: Continuous spectrum (discretized)
- complexity: O(N^2) direct; O(N log N) via FFT

## D6-X02 Duhamel propagation of a source

*Transformer; composition, construction; origin: added*

Solves an inhomogeneous linear evolution by superposing homogeneous evolutions started at all earlier times, each with the source at that time as its initial impulse: u(t) = integral from 0 to t of G(t,s) f(s) ds, with G the propagator.

- input: Linear evolution operator (a propagator G(t,s)), source f(s)
- output: The solution u(t), or its projection onto a chosen mode: the integral of the pairing of G(t,s)* applied to the mode with f(s)
- preserved: Linearity: sources superpose; causality (only earlier times contribute)
- broken: Instantaneous locality: a source's effect at time t depends on its whole propagated history, so a pairing that vanishes at each instant can be nonzero after propagation
- complexity: N/A
